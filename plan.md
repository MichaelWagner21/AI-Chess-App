# Chess Puzzle App Plan

## Goal

Build a small browser-based app for chess enthusiasts who already know the game and want to practice tactics by solving chess puzzles.

## First-version must-haves

1. **Interactive chessboard:** Players move pieces directly on the board to enter their solutions.
2. **Multi-move puzzles:** Puzzles require a sequence of moves, with the opponent's replies shown between the player's moves.
3. **Retry after mistakes:** A wrong move lets the player try again instead of immediately revealing the solution.

## Optional for later

- Let players choose puzzle difficulty. For the first version, difficulty selection can wait.

## Implementation constraints

- Run in a browser using only HTML, CSS, and JavaScript.
- No code should be written until the plan has been reviewed and edited as needed.
